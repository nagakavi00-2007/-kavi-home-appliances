# Project

A React + Vite storefront app.

## Prerequisites

1. Clone the repository.
2. Navigate to the project directory.
3. Install dependencies:

```bash
npm install
```

## Run Locally

```bash
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## Notes

- Keep environment files local and do not commit secrets.
- Use the project defaults in `package.json` for the standard local workflow.
